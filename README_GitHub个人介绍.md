## 代表项目

### [CareerAI](https://github.com/AdrianFeng10086/CareerAI)

一个面向求职者的 AI 职业规划辅助系统，尝试把岗位数据、市场分析、人岗匹配、RAG 职业规划和模拟面试整合到一个应用中。

主要实践包括：

- Python / Flask Web 服务
- 岗位数据抓取与结构化分析
- 基于向量检索的职业规划建议
- AI 模拟面试与反馈
- OpenCV 摄像头神态分析
- 本地数据存储与多用户隔离设计
